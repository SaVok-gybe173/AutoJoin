# AutoJoin

**AutoJoin** — это скрипт для автоматического входа на сервер **GribLand** в Minecraft. Он находит окно игры, определяет игрока и сервер, а затем выполняет последовательность действий (кликов в заданных координатах) для автоматического подключения.

---

## Готовая сборка для запуска 

1. **Скачайте AutoJoin-win64-x86.zip:**
    https://github.com/SaVok-gybe173/AutoJoin/releases/tag/v1.0.0
    
2. **Запустите exe:**
    AutoJoin.exe

## Ручная установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/SaVok-gybe173/AutoJoin.git
   cd AutoJoin
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
   или воспользуйтесь готовыми скриптами:
   - `setup.bat` — для Windows
   - `setup.sh` — для Linux/macOS

3. **Запустите скрипт:**
   ```bash
   python main.py
   ```

## Конфигурация

Все настройки хранятся в файле **`settings.ini`** в корневой папке проекта. Если файл отсутствует, при первом запуске он будет создан автоматически со стандартными параметрами.

### Структура файла `settings.ini`

```ini
[SETTINGS]
time_turnaround = 0.3
time = 0.1
start_stop = 1
is_save = yes
stop = f7
home = no

[POSITION1]
x = 0.3
y = 0.45
key = 8
percent = 90
modul = POSITION1

[POSITION2]
x = 0.4
y = 0.45
key = 9
percent = 90
modul = POSITION2

[POSITION3]
x = 0.5
y = 0.6
key = 0
percent = 90
modul = POSITION3

[NOME]
comand = /home
modul = NOME
```

---

### Описание секций и параметров

#### `[SETTINGS]` — основные настройки скрипта

| Параметр | Тип | Описание |
|----------|-----|----------|
| `time_turnaround` | float | Время ожидания между действиями (в секундах) |
| `time` | float | Базовая задержка перед выполнением клика |
| `start_stop` | int | `1` — скрипт активен, `0` — остановлен |
| `is_save` | yes/no | Сохранять ли скриншоты (если включено в коде) |
| `stop` | str | Клавиша для остановки скрипта (например, `f7`) |
| `home` | yes/no | Включить ли выполнение команды `/home` из секции `[NOME]` |

---

#### `[POSITION1]`, `[POSITION2]`, `[POSITION3]` — позиции для кликов

Каждая секция описывает одну точку, в которую будет совершён клик. Координаты задаются **в относительных величинах** (от 0 до 1) относительно размеров окна игры.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `x` | float | Относительная координата X (0.0 — левый край, 1.0 — правый) |
| `y` | float | Относительная координата Y (0.0 — верх, 1.0 — низ) |
| `key` | int | Код клавиши (не используется в текущей версии, зарезервировано) |
| `percent` | int | Процент (не используется в текущей версии, зарезервировано) |
| `modul` | str | Имя модуля, который обрабатывает данную позицию. Должно совпадать с названием секции |

**Как это работает:**  
Скрипт получает размеры окна (`width`, `height`) и вычисляет абсолютные координаты по формуле:
```
абс. X = x_отн × width
абс. Y = y_отн × height
```
Затем перемещает курсор в эту точку и эмулирует клик.

---

#### `[NOME]` — дополнительная команда

| Параметр | Тип | Описание |
|----------|-----|----------|
| `comand` | str | Команда, которая будет отправлена в чат игры (например, `/home`) |
| `modul` | str | Имя модуля (должно быть `NOME`) |

Эта секция активируется, если в `[SETTINGS]` параметр `home` установлен в `yes`.

## Модульная система

Скрипт поддерживает **динамическую загрузку модулей** для каждой позиции.  
Код модуля генерируется автоматически на основе параметров из `settings.ini` и сохраняется в папку:
```
data/{имя_сервера}/lib/
```


Стандартные модули (`POSITION1`, `POSITION2`, `POSITION3`) уже встроены в `config.py`. Вы можете создавать свои модули, добавляя их в список `IMPORTMODUL_LIST` в `config.py`.

## Зависимости

Основные библиотеки (указаны в `requirements.txt`):

- `pyautogui` — автоматизация GUI
- `rich` — красивый вывод в консоль
- `termcolor` — цветной текст
- `pyfiglet` — ASCII-арт

##  Управление

- **Запуск** — `python main.py`
- **Остановка** — нажмите клавишу, указанную в `stop` (по умолчанию `F7`)

---

## Примечания

- Скрипт ищет окна с заголовком, содержащим `GribLand | {сервер} | {игрок}`.
- Если окно не найдено, скрипт будет ждать его появления.
- Все координаты в `settings.ini` задаются **относительно** — это позволяет корректно работать при любом разрешении экрана и размере окна.
